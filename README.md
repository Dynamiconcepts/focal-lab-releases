# Focal Lab downloads

This public repository holds Focal Lab Mac installers, release notes and update feeds. Application source is maintained separately in a private repository.

Version 0.5.1 is being tested on the Mac. No installer has been published here yet. The feeds remain empty until a verified package is ready.

Personal previews do not require paid Apple membership, but are not Developer ID signed or notarized. The signed DMG remains pending.
